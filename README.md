# 水溶液ミステリー

小学6年 理科「水溶液の性質」のまとめで使う推理ゲーム。謎のびん（初級3本・中級4本・上級5本）に入った水溶液を、回数の決まった実験（見る・におう・蒸発させる・リトマス紙またはBTB溶液）で当てる。

- 仕様書（docs/）とワイヤーフレーム（wireframes/）は公開していない
- 学校のiPad（横画面）向け。データは端末の中だけに保存（名前は入力しない）
- ビルド不要（HTML・CSS・JavaScriptだけ）

## 手元で動かす

ES モジュールを使うので、ファイルを直接開くのではなく、このフォルダで簡易サーバーを立てて開く。

```powershell
python -m http.server 5183
```

ブラウザで http://localhost:5183 を開く。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 入口 |
| `css/style.css` | 見た目（デザインシステム「放課後の理科室」） |
| `js/data.js` | 液の性質・結果の言葉・称号（理科の内容はここだけ） |
| `js/game.js` | ルール・判定・端末内の保存 |
| `js/art.js` | びん・実験道具の絵と、実験の演出 |
| `js/main.js` | 画面と操作 |

GitHub Pages（main のルート）でそのまま動く。
